# Tripleten web_project_homeland

Homeland page: De patria para patria, tem o objetivo de mostrar a cidade natal dos integrantes da TripleTen, reunidos de todos os cantos do mundo.

## Recursos do projeto

- HTML5 semântico
- Flexbox
- Posicionamento
- Dimensionamento relativo
- Consultas de media
